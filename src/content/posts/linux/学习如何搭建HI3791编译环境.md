## 二、软件版本准备
### 1. 获取kernel5.10源码
从FAE获取Common-Kernel-5.10源码
R100X_V735R001C00SPC010B020_Software_Kernel-5.10.tar.gz

也可从Android官网下载：
```sh
https://android.googlesource.com/kernel/common/+archive/870488eb0745645feff5bddfd44fe538660b9cf8.tar.gz
```

当前 common-870488eb0745645feff5bddfd44fe538660b9cf8.tar.gz 是从git拉取的
```sh
git clone https://github.com/aosp-mirror/kernel_common.git
git checkout 870488eb0745645feff5bddfd44fe538660b9cf8
```

将Kernel原生代码的压缩包拷贝到指定目录，并执行如下命令进行解压：
mkdir -p hl_src/vendor/open_source/common-kernel-5.10  
tar xvf common-870488eb0745645feff5bddfd44fe538660b9cf8.tar.gz -C hl_src/vendor/open_source/common-kernel-5.10/
mv hl_src/vendor/open_source/common-kernel-5.10/kernel_common/* hl_src/vendor/open_source/common-kernel-5.10/


### 2. 合入软件包
#### i. 合入基础软件发布包到hl_src代码目录中
```sh
tar xzvf R100X_V735R001C00SPC010B020_Software_Base-package.tar.gz -C hl_src
```

#### ii. 合入标准Linux patch包(咨询FAE获取)到hl_src代码目录中。（此包为rootfs包）
```sh
tar xzvf R100X_V735R001C00SPC010B020_Software_Linux-package.tar.gz -C hl_src
```

#### iii. 合入标准Sample patch包(咨询FAE获取)到hl_src代码目录中。(此步骤可选)
```sh
tar xzvf R100X_V735R001C00SPC010B020_Software_Sample-package.tar.gz -C hl_src
```

#### iv. 执行hl_src目录下clean.sh脚本。
```sh
cd hl_src  
./clean.sh
```

## 三、镜像编译
### 1. 环境配置。
执行命令：
```sh
cd hl_src/linux  
source build/env.sh  
lunch mp730-eng
```

### 2. 执行如下命令进行编译。
本步骤路径中的“xx”均表示mp730。
#### i. 完整编译。
进入代码目录 hl_src/linux  下，执行命令：
```sh
./build.sh HUANGLONG_PLATFORM_VERSION=R100XV735R001C00SPC010B020
```
镜像路径：out/target/product/xx/images。

#### ii. 编译Linux内核分区镜像。
进入代码根目录下，执行命令：
```sh
./build.sh bootimg HUANGLONG_PLATFORM_VERSION=R100XV735R001C00SPC010B020
```
此命令会编译出下面的镜像：
boot_d.img
此镜像会拷贝至out/target/product/xx/images目录下。
编译过程文件存放在：
out/target/product/xx/obj/KERNEL_OBJ_D/

#### iii. 编译eMMC 器件上的Linux 系统分区镜像。
进入代码根目录下，执行命令：
```sh
./build.sh rootbox |tee userdataimage.log 
```
此命令会编译出下面的镜像，out/target/product/xx/目录下：
rootfs.ext4 

#### iv. 编译bootloader相关镜像。
进入代码根目录下，执行命令：
```sh
./build.sh bootloader HUANGLONG_PLATFORM_VERSION=R100XV735R001C00SPC010B020
```
此命令会编译出下面的镜像：
fastboot_d.bin  
programmer_d.bin  
sbl_d.bin  
slaveboot_d.bin
此镜像会拷贝至out/target/product/xx/images目录下。
编译过程文件存放在：
out/target/product/xx/obj/EMMC_FIRSTBOOT_OBJ_D/  
out/target/product/xx/obj/EMMC_PROGRAMMER_OBJ_D/  
out/target/product/xx/obj/EMMC_SECONDBOOT_OBJ_D/  
out/target/product/xx/obj/EMMC_SLAVEBOOT_OBJ_D/

#### v.编译dtb镜像。
进入代码根目录下，执行命令：
./build.sh dtboimage
此命令会编译出下面的镜像：
dtbo_d.img
此镜像会拷贝至out/target/product/xx/images目录下。
编译过程文件存放在：
out/target/product/xx/

#### vi.编译bootargs镜像。
进入代码根目录下，执行命令：
```sh
./build.sh bootargs
```
此命令会编译出下面的镜像：
bootargs.bin

此镜像会拷贝至out/target/product/xx/images目录下。

#### vii.清除编译结果。
```sh
./build.sh clean
```
